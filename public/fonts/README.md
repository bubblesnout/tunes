# Fonts

Tunes uses **Motiva Sans** (Steam Big Picture's typeface). It's free for personal use
but not redistributable, so the font files are **not committed** to this repository.

Place these files here before building (they're git-ignored):

```
MotivaSans-Thin.ttf        (100)
MotivaSans-Light.ttf       (300)
MotivaSans-Regular.ttf     (400)
MotivaSans-Medium.ttf      (500)
MotivaSans-Bold.ttf        (700)
MotivaSans-ExtraBold.ttf   (800)
MotivaSans-Black.ttf       (900)
```

Without them the app still builds and runs, falling back to Segoe UI / system sans-serif.
